## 🎯 О проекте

**FinWise** — это мобильное приложение для iOS и Android, которое автоматизирует учёт личных финансов с использованием технологий машинного обучения. Приложение позволяет сканировать чеки и автоматически категоризировать расходы, прогнозировать будущие траты и получать персонализированные советы по оптимизации бюджета.

### Ключевые возможности

✨ **Автоматизация учёта**
- Сканирование QR-кодов на чеках (российские фискальные чеки)
- OCR распознавание бумажных чеков
- Автоматическое создание транзакций из чеков с детализацией по товарам

🤖 **Искусственный интеллект**
- ML-категоризация расходов с точностью ~98.50% (LinearSVC + NLP предобработка pymorphy2)
- **Pure Dart Offline ML** — LinearSVC модель встроена в приложение (~98.40% без интернета)
- Персонализированные рекомендации по экономии (4 типа советов)
- Обнаружение аномальных трат (z-score, 2σ, без интернета)

📊 **Аналитика и визуализация**
- Круговые и сгруппированные столбчатые диаграммы (доходы vs расходы)
- 4 периода анализа: День / Неделя / Месяц / Год
- Экран поиска с фильтрацией по тексту, категории, дате и типу
- Экран-календарь: просмотр трат по дням и категориям за месяц
- **Прогноз расходов на следующий месяц** (weighted linear regression, офлайн, доверительный интервал ±18%)
- Отслеживание прогресса бюджета в реальном времени

📱 **Адаптивный интерфейс**
- Responsive дизайн: NavigationRail для планшетов и landscape
- Ограничение ширины контента (maxWidth 720dp) на широких экранах
- Онбординг туториал (spotlight overlay на 3 ключевых элемента)

🔒 **Приватность и безопасность**
- Офлайн-первый подход: данные хранятся локально
- Шифрование sensitive данных (AES-256)
- **Синхронизация между устройствами** (JWT auth, push/pull через backend)

## 🔍 Проблематика

### Существующие проблемы рынка финансовых приложений:

1. **Ручной ввод данных** — утомительный процесс записи каждой траты
2. **Низкая точность автокатегоризации** — большинство приложений используют простые правила
3. **Отсутствие прогнозов** — пользователи не знают, сколько потратят в будущем
4. **Зависимость от банковской интеграции** — не работает для наличных или карт без API
5. **Отсутствие детализации** — чек на 5000₽ в продуктовом записывается одной строкой
6. **Общие советы** — рекомендации не учитывают индивидуальные привычки

### Целевая аудитория

- 👨‍💼 **Молодые специалисты** (25-35 лет) — хотят контролировать расходы, но не имеют времени на ручной учёт
- 👨‍👩‍👧‍👦 **Семьи** — нужна детализация трат по категориям (продукты, дети, дом)
- 💰 **Фрилансеры** — нерегулярные доходы, важен прогноз и планирование
- 🎓 **Студенты** — ограниченный бюджет, нужны советы по экономии

## 💡 Решение

**FinWise** решает проблему автоматизации учёта через:

1. **Сканирование чеков** → Минимизация ручного ввода (QR + OCR)
2. **ML категоризация** → Точность ~98% (LinearSVC + word/char n-grams на 5008 примерах)
3. **Детализация** → Чек разбивается на отдельные товары с категориями
4. **Персональные советы** → Анализ паттернов и конкретные рекомендации (4 типа)
5. **Offline-first** → Работает без интернета с fallback на локальный словарь
6. **Планируемые транзакции** → Повторяющиеся расходы (ежедневно/еженедельно/ежемесячно/ежегодно)

### 1. Модель категоризации транзакций

**Задача:** Автоматически определить категорию на основе описания транзакции

#### Алгоритм: LinearSVC + NLP предобработка

**Почему LinearSVC?**
- ✅ Лучший алгоритм для разреженных TF-IDF матриц (доказано в NLP литературе)
- ✅ Точность 98.50% на 5008 примерах — значительно лучше Random Forest (87.90%)
- ✅ Быстрый inference (~15ms на предсказание)
- ✅ Не требует GPU (подходит для сервера с 2GB RAM)
- ✅ CalibratedClassifierCV даёт вероятности (confidence score)

#### Feature Engineering

```python
# NLP предобработка (pymorphy2)
text = preprocess(description)  # лемматизация + стоп-слова

# FeatureUnion: word n-grams + char n-grams
vectorizer = FeatureUnion([
    ("word", TfidfVectorizer(
        analyzer="word",
        ngram_range=(1, 2),   # uni + bigrams
        max_features=2000,
        sublinear_tf=True,
    )),
    ("char", TfidfVectorizer(
        analyzer="char_wb",
        ngram_range=(3, 5),   # символьные n-граммы
        max_features=2000,
        sublinear_tf=True,
    )),
])
# Итого: 4000 признаков (word + char)
```

### 2. Модель прогнозирования расходов

**Задача:** Предсказать расходы пользователя на следующий месяц

#### Алгоритм: Взвешенная линейная регрессия (Weighted Linear Regression)

**Почему WLR, а не Prophet?**
- ✅ Работает полностью офлайн — не требует сервера
- ✅ Работает на малых данных (от 2 ненулевых месяцев)
- ✅ Более свежие месяцы имеют больший вес (реакция на смену привычек)
- ✅ Нулевые зависимости — чистый Dart код
- ✅ Мгновенное предсказание (~1ms)

#### Процесс прогнозирования

```mermaid
flowchart TB
    A[История транзакций] --> B[Скользящее окно<br/>последние 6 месяцев]
    B --> C{Ненулевых ≥ 2?}
    C -->|Нет| D[Нет прогноза]
    C -->|Да| E[Взвешенная ЛР<br/>w_i = i+1 newer→heavier]
    E --> F[Предсказание total]
    F --> G[Доверительный интервал<br/>±18%]
    G --> H[Топ-5 категорий]
    H --> I[Карточка прогноза в UI]
```

**Алгоритм:**
```dart
// lib/services/forecast_service.dart
static double _weightedLinearRegression(List<double> values) {
  final n = values.length;
  // Вес = позиция: w_0=1, w_1=2, ..., w_N=N (более свежие = тяжелее)
  double sumW = 0, sumWX = 0, sumWY = 0, sumWXX = 0, sumWXY = 0;
  for (int i = 0; i < n; i++) {
    final w = i + 1.0;
    sumW += w; sumWX += w * i; sumWY += w * values[i];
    sumWXX += w * i * i; sumWXY += w * i * values[i];
  }
  // Коэффициенты: intercept + slope * n → предсказание следующей точки
  final slope = (sumW * sumWXY - sumWX * sumWY) / (sumW * sumWXX - sumWX * sumWX);
  final intercept = (sumWY - slope * sumWX) / sumW;
  return (intercept + slope * n).clamp(0, double.infinity);
}
```

**Алгоритм:**
```python
def categorize_receipt_items(items, retailer_name):
    categories = []

    for item in items:
        # 1. Проверка названия товара через ML модель
        category = ml_model.categorize(item.name)

        # 2. Если confidence низкий, используем магазин
        if category.confidence < 0.7:
            category = categorize_by_retailer(retailer_name)

        # 3. Если всё ещё не определено, используем словарь
        if category.confidence < 0.5:
            category = keyword_dictionary.match(item.name)

        categories.append(category)

    return categories
```

3. **Локальный словарь ключевых слов** (резервный fallback) → точность ~75%
4. **Fallback** → категория "Прочее"

## 💎 Инновации и преимущества

### 1. Детализация чеков до уровня товаров

**Проблема:** Все конкуренты записывают чек одной строкой
```
❌ Пятёрочка  -1,250₽  [Продукты]
```

**Наше решение:**
```
✅ Хлеб белый        -45.50₽  [Продукты]
✅ Молоко 3.2%      -179.80₽  [Продукты]
✅ Сигареты         -250.00₽  [Вредные привычки]
✅ Пиво 0.5л        -120.00₽  [Алкоголь]
```

**Преимущества:**
- 📊 Более точная аналитика: "Вы тратите 3,000₽/мес на сигареты"
- 💡 Конкретные советы: "Отказ от курения сэкономит 36,000₽/год"
- 🔍 Поиск по товарам: "Покажи все покупки молока за 3 месяца"

### 2. Обучаемая ML модель

**Проблема:** Конкуренты используют статичные правила
```python
if "такси" in description:
    category = "Транспорт"
```

**Наше решение:** Random Forest + TF-IDF с обучением на 1238 примерах
```python
# Текущая реализация (v1.0):
# - Random Forest: 100 деревьев, max_depth=20
# - TF-IDF: 500 features, unigrams + bigrams
# - Точность: 87.90% на тестовом датасете

# Планируется (v2.0):
# - Персонализация: модель учится на исправлениях пользователя
# - Ожидаемая точность: 87% → 90% → 93% со временем
```

### 3. Прогнозирование с учётом сезонности

**Пример:** Модель знает, что:
- В начале месяца (зарплата) → больше трат
- В выходные → больше ресторанов и развлечений
- Перед праздниками → рост на 40%
- Летом → больше путешествий

```
Прогноз на февраль: 47,000₽
┌─────────────────────────────────┐
│ 14 фев (День Влюблённых)        │
│ Ожидается +8,000₽ на:           │
│ • Рестораны (+5,000₽)           │
│ • Подарки (+3,000₽)             │
└─────────────────────────────────┘
```

### 4. Offline-First архитектура с встроенным ML

**Проблема:** Конкуренты требуют постоянный интернет для работы; офлайн ML — редкость

**Наше решение:**
- ✅ Все функции работают офлайн
- ✅ **Pure Dart Offline ML** — LinearSVC модель (4000 признаков, 30 категорий) встроена в приложение (~2.9MB assets)
- ✅ Офлайн точность ~98.40% — практически идентична серверной (98.50%)
- ✅ Автоматическая синхронизация в фоне
- ✅ Никаких задержек и зависаний

**Преимущество:** Работает в метро, за городом, в роуминге — с полноценным ML, а не словарём

### 5. Приватность данных

**Конкуренты:**
- Дзен мани: данные в облаке, требуется аккаунт
- Wallet: синхронизация через сервер, анализ на стороне сервера

**FinWise:**
- 🔒 Данные хранятся локально на устройстве
- 🔒 Сервер используется только для ML (анонимные запросы)
- 🔒 Опциональная синхронизация (можно отключить)
- 🔒 Можно использовать без регистрации

### 6. Конкретные советы вместо общих

**Конкуренты:**
```
⚠️ "Вы превысили бюджет на 15%"
💡 "Попробуйте меньше тратить"
```

**FinWise:**
```
⚠️ "Вы потратили 52,500₽ при бюджете 45,000₽"

💡 Конкретные рекомендации:
1. Кофе в кофейнях: 4,500₽/мес → Сварите дома → экономия 3,000₽
2. Такси 12 поездок: 8,500₽ → Купите проездной → экономия 5,500₽
3. Netflix + Spotify: 338₽ → Семейная подписка → экономия 169₽

Итого можно сэкономить: 8,669₽/мес = 104,028₽/год
```
